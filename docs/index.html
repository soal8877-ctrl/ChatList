ChatList

Отправьте один промт в несколько бесплатных моделей OpenRouter, сравните ответы и сохраните лучшие.

v1.0.0 · Windows
Скачать установщик Все релизы GitHub

Возможности

  • Несколько моделей — один промт, несколько ответов в таблице
  • OpenRouter Free — только бесплатные модели :free
  • AI-ассистент — улучшение и переформулировка промтов
  • SQLite — сохранение промтов и результатов
  • Экспорт — Markdown и JSON
  • Тема и шрифт — светлая/тёмная тема, размер шрифта

Быстрый старт

  1. Скачайте и установите ChatList-setup.exe.
  2. Скопируйте .env.example в .env в папке программы.
  3. Укажите ключ OPENROUTER_API_KEY — получить на openrouter.ai/keys.
  4. Запустите ChatList, включите модели в меню «Модели» и нажмите «Отправить».

Требования

  • Windows 10/11 (64-bit)
  • Ключ API OpenRouter (бесплатный тариф с лимитами)
  • Интернет-соединение
